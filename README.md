# CYBER SEC

Локальная интерактивная платформа, чтобы **понять, как всё работает под капотом**:
компьютеры, ОС, сети, код, информационная безопасность. Обучение через практику,
интерактивные визуализации и проверку понимания — с движком памяти, который заставляет
знания держаться (интервальное повторение + доучивание до критерия + граф компетенций).

## Запуск

Самый простой способ — **двойной клик по `index.html`**. Всё работает офлайн,
прогресс сохраняется в браузере. Ничего ставить не нужно.

Для http-режима (например, чтобы работала кнопка «копировать команду») и для тестов
нужен Node:

```bash
npm run serve     # открой http://localhost:8080
npm test          # автотесты логики, ядра памяти и валидатор контента
```

## Как пользоваться
1. Пройди **диагностику** (2 минуты) — подберёт стартовую глубину и отметит, что ты уже знаешь.
2. Заходи в **«Сегодня»** — план собран по науке о памяти: добить слабое → повторить вперемешку → взять новое.
3. Внутри урока: сначала *пробуешь сам*, потом *видишь, как на самом деле*, потом *делаешь руками* (реальные команды у себя), в конце — *проверка*.
4. Возвращайся к **повторению** по расписанию — это главный механизм долгой памяти.

Три режима глубины (вверху): **Foundation** (фундамент), **Deep Dive** (протоколы и диагностика),
**Expert Lab** (сложная самостоятельная практика).

## Перенести прогресс / отдать другу
Меню `⋯` → **Экспорт профиля** (JSON). На другом ПК — тот же пункт → **Импорт**.
Чтобы отдать платформу другу — просто скопируй всю папку.

## Структура
- `index.html`, `css/`, `js/` — приложение (без сборки).
- `content/*.js` — курсы (данные). Новый курс = новый файл + строка `<script>` в `index.html`.
- `tests/` — автотесты (`npm test`).
- `METHOD.md` — петля урока · `SCHEMA.md` — формат контента · `LEARNING_ENGINE.md` — механизмы памяти · `PROJECT_PLAN.md` — состояние и планы.

## Этика (безопасность)
Весь практикум по информационной безопасности — **только** для локальных учебных
симуляторов, собственных лабораторий, CTF и явно разрешённых сред. Никаких рабочих
эксплойтов и действий против чужих систем: подход всегда «механизм → симуляция →
как чинить и как обнаружить».

## v0.3 — большая сфера обучения

- **Фундамент → ядро → ветки**: 14 направлений, 117 тем в плане (55 готовы), карта-граф зависимостей на `#/map`.
- **Новые курсы**: железо, как программа становится процессом, как работают игры, приложения и сайты, программирование с нуля (код с автотестами), 4 курса по сетям (TCP/IP, коммутация и маршрутизация, HTTP/TLS, анализ трафика), 2 курса OSINT.
- **CryptoLab** (`cryptolab/`, репозиторий nlovx/cryptolab) встроен как трек «Криптография»: 38 комнат, прогресс виден на карте.
- **Справочник** `#/docs`, 16+ интерактивных виджетов, тема Liquid Glass.
- **Аккаунты и история обучения**: `start.bat` (или `node tools/server.mjs`) — регистрация, вход, синхронизация прогресса на сервере (`data/`), страница «Мой прогресс».

### Запуск для друзей
`start.bat` → http://localhost:8080. Подробности — в справочнике «Как открыть платформу друзьям». Код-приглашение: `set INVITE_CODE=...`.
Обновить CryptoLab: заменить `cryptolab/content.js` и `cryptolab/index.html` свежими файлами (в index.html сохранить блок синхронизации и ссылку «← CYBER SEC»).
