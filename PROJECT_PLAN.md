# CYBER SEC — план проекта и состояние

Локальная интерактивная платформа для изучения компьютеров, ОС, сетей, кода и
информационной безопасности. Запуск без сборки: двойной клик по `index.html`
(или `npm run serve` для http). Прогресс — в `localStorage`, переносится экспортом JSON.

## Архитектура (кратко)
- `index.html` — оболочка, подключает ядро и курсы `<script>`-тегами (no-build).
- `js/srlogic.js` — чистая логика: адаптивная диагностика, проверка ввода, базовое мастерство.
- `js/mastery.js` — **ядро памяти** (FSRS-модель, successive relearning, граф, калибровка, оценка).
- `js/engine.js` — реестр курсов, прогресс, граф компетенций, дневной план, экспорт/импорт.
- `js/viz.js` — интерактивные виджеты (binary, dns, packet, subnet).
- `js/ui.js` — роутер и все экраны (карта, курс, плеер урока, Сегодня, повторение, диагностика).
- `content/*.js` — курсы (данные + разметка), самo-регистрируются через `CS.course(...)`.
- `tests/` — автотесты логики, ядра памяти и валидатор контента (`npm test`).
- Документы: `METHOD.md` (петля урока), `SCHEMA.md` (формат контента), `LEARNING_ENGINE.md` (механизмы памяти).

## Критерии готовности курса (definition of done)
- Каждый урок: `hook` → попытка до объяснения → визуализация/эталон → объяснение → практика → финальная проверка.
- Есть карточки (уходят в интервальное повторение) и источники (http/https).
- Проходит `npm test` (валидатор). Открывается и проходится в браузере без ошибок консоли.
- Deep/Expert ветки добавляют реальную глубину (байты/RFC/как ломается и как чинить), а не длину текста.
