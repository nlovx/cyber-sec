# CYBER SEC — схема контента

Курсы — это обычные `.js`-файлы в `content/`, которые при загрузке сами
регистрируются через глобальный вызов `CS.course({...})`. Никакой сборки нет:
файлы подключаются `<script>`-тегами в `index.html`, движок собирает их в реестр.
Поэтому курс = данные + немного разметки, логика живёт в движке.

Почему так: контент отделён от логики (можно писать курсы, не трогая ядро),
работает по `file://` без сервера (двойной клик по `index.html`), легко отдать другу.

---

## Курс

```js
CS.course({
  id:       'pc',              // уникальный slug, [a-z0-9-]
  title:    'Как устроен компьютер',
  track:    'base',            // base | sysadmin | net | security | redteam | programming | forensics | osint | cloud
  order:    1,                 // порядок внутри трека
  glyph:    '▣',               // короткий символ для карточки курса
  tagline:  'Одна строка под заголовком',
  about:    'Абзац: что ты будешь уметь после курса (результат, а не оглавление).',
  needs:    ['pc'],            // (опц.) id курсов-пререквизитов
  assess:   [ <AssessItem>... ],   // входная диагностика/ассесмент курса
  lessons:  [ <Lesson>... ]
});
```

### AssessItem — вопрос диагностики
```js
{ id:'pc-a1', b:-1, q:'Вопрос?', options:['A','B','C','D'], correct:0,
  why:'Разбор: почему правильный верен и чем плохи типичные неверные.' }
```
- `b` — сложность по шкале IRT-lite: `-1` лёгкий, `0` средний, `+1` сложный.
- `correct` — индекс правильного варианта в `options`.
- Диагностика адаптивная (лестница): верно → следующий вопрос сложнее, неверно → легче.
  Итог поднимает стартовую оценку мастерства темы, чтобы «кто уже знает — проскакивал».

## Lesson

```js
{
  id:       'pc-binary',   // уникальный в рамках проекта
  title:    'Биты, байты и hex',
  subtitle: 'Одна строка: что пощупаешь и поймёшь',
  minutes:  11,            // оценка времени
  boss:     false,         // true = итоговый интерлив-урок курса
  steps:    [ <Step>... ],
  cards:    [ ['Вопрос карточки','Короткий ответ'], ... ],  // уходят в интервальное повторение
  sources:  [ {label:'MDN: ...', url:'https://...'} ]
}
```

## Step — шаги урока (петля из METHOD.md)

У каждого шага есть `t` (тип). Поля зависят от типа.
Режим глубины управляет видимостью: `deep` виден в Deep Dive+, `expert` — в Expert Lab.
Критичные шаги (`hook/viz/say/quiz/input/match/real/case/check`) видны во всех режимах.

| `t`     | Назначение (METHOD) | Поля |
|---------|---------------------|------|
| `hook`  | ситуация, curiosity gap | `title`, `text` |
| `viz`   | интерактивная визуализация | `kind`, `title`, `text` — `kind` см. ниже |
| `say`   | объяснение: аналогия → термин | `title`, `simple`, `text` |
| `quiz`  | выбор из вариантов (retrieval) | `q`, `options[]`, `correct`, `why`, `ctx?` |
| `input` | свободный ответ | `q`, `answers[]` (принимаемые, регистр/пробелы игнор), `why`, `ctx?`, `hint?` |
| `match` | сопоставить пары | `q`, `pairs[[left,right]]`, `why` |
| `deep`  | «под капотом» (Deep Dive+) | `title`, `text` |
| `expert`| экспертный разбор (Expert Lab) | `title`, `text` |
| `real`  | практика на своём ПК | `title`, `os` (`win`/`lin`/`any`), `steps[{cmd,text}]` |
| `case`  | реальный публичный инцидент | `title`, `text` |
| `check` | явная проверка-ретривал (как `quiz`/`input`, но помечает мастерство) | как `quiz` или `input` + `kind:'quiz'\|'input'` |

Текст поддерживает мини-markdown: `**жирный**`, `` `код` ``, `\n` — абзацы.

### `viz.kind` — зарегистрированные виджеты (`js/viz.js`)
- `binary` — щёлкать 8 бит, видеть десятичное/hex.
- `dns` — кликать этапы разрешения имени (browser→resolver→root→TLD→authoritative).
- `packet` — слои инкапсуляции пакета (Ethernet/IP/TCP/HTTP).
- `subnet` — делитель подсети: ввести CIDR, увидеть диапазон/маску/хосты.

Новый виджет: добавить `CS.viz('kind', renderFn)` в `js/viz.js`. Неизвестный `kind`
деградирует до текстового блока (`title`+`text`) — урок не ломается.

## Оценка знаний и повторение (движок)

- **Мастерство темы** `m ∈ [0,1]` на урок: растёт за верные ретривалы, падает за ошибки
  (экспоненциальное сглаживание). Урок «освоен» при `m ≥ 0.8` и пройденной финальной проверке.
- **Интервальное повторение** карточек: SM-2-подобно. Интервалы-база `1→3→7→16→35` дней,
  множитель `ease` подстраивается по самооценке (`again/hard/good/easy`). См. `js/srlogic.js`.
- **Правило 2 ошибок**: после 2 неверных попыток показываем ответ с разбором (hypercorrection).

Весь прогресс — в `localStorage` (`cybersec.state.v1`), переживает перезагрузку.
Экспорт/импорт профиля — JSON (кнопка в шапке), чтобы перенести на другой ПК или отдать другу.
